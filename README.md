# Медиа-фабрика

Небольшая «контент-фабрика»: инструменты, которые готовят посты и публикуют их в соцсети
через официальные API. Сейчас в ней есть один инструмент — постер (ниже).

Ключи и токены хранятся только в файле `.env` в корне репозитория (`chmod 600`, в git не
попадает), по строке `ИМЯ=значение`. Имена переменных перечислены в `KEYS.md`, например
`FB_PAGE_KOTLETA_ID`, `FB_PAGE_KOTLETA_TOKEN`, `X_API_KEY`, `LINKEDIN_CLIENT_ID`. Значения
нигде в репозитории не хранятся и не печатаются.

## Постер

`python3 -m poster` публикует один **пакет поста** сразу в несколько сетей: страницу Facebook,
Instagram (бизнес-аккаунт), X и личный профиль LinkedIn. Для каждой сети в пакете свой текст
и своя картинка (или без картинки), поэтому пост не дублируется, а подогнан под сеть.
Только стандартная библиотека Python 3.12, ничего ставить не нужно. Подробный дизайн:
`docs/design/poster.md`.

### Настройка (один раз)

1. Ключи лежат в `.env` в корне репозитория (`chmod 600`, в git не попадает). Другой файл:
   `--env-file ПУТЬ` или переменная `MF_ENV_FILE` (например, из другой рабочей копии, где
   своего `.env` нет).
2. Имена переменных (полный список в `KEYS.md`; значения только в `.env`):
   - `LINKEDIN_ACCESS_TOKEN`, `LINKEDIN_TOKEN_EXPIRES_AT`, `LINKEDIN_PERSON_URN` —
     записывает команда `login linkedin`;
   - необязательные настройки: `META_GRAPH_VERSION` (по умолчанию `v27.0`),
     `LINKEDIN_API_VERSION` (`202610`), `X_MONTHLY_CAP_USD` (`5.00`), `X_PRICE_POST` (`0.015`),
     `X_PRICE_POST_WITH_URL` (`0.200`), `X_PRICE_POST_WITH_MEDIA` (`0.200`),
     `X_PRICE_MEDIA_UPLOAD` (`0.015`).
3. LinkedIn: в приложении на developer-портале LinkedIn добавить продукты «Share on LinkedIn»
   и «Sign In with LinkedIn using OpenID Connect», на вкладке Auth в «Authorized redirect URLs»
   внести ровно `http://localhost:8765/callback`. Затем:

   ```
   python3 -m poster login linkedin
   ```

   Команда печатает ссылку, вы нажимаете Allow, токен и срок действия (60 дней) записываются
   в `.env`. Продление — та же команда; за 7 дней до конца `status` и `publish` предупреждают.

### Пакет поста

JSON-файл в `content/packages/` (папка `content/` не попадает в git):

```json
{
  "schema": 1,
  "id": "2026-11-09-halving",
  "theme": "О чём пост (никуда не публикуется)",
  "variants": {
    "facebook":  {"text": "Длинный текст для страницы", "image": "halving.jpg"},
    "instagram": {"text": "Подпись #bitcoin", "image": "halving-square.jpg"},
    "x":         {"text": "Одна острая цитата"},
    "linkedin":  {"text": "Профессиональный угол", "image": "photos/desk.png"}
  },
  "meta": {"source": "chat"}
}
```

- Картинка без `/` — имя из библиотеки `content/images/` (другая папка: `--library` или
  `MF_IMAGE_LIBRARY`); с `/` — путь к файлу (относительный — от папки пакета).
  Картинки отправляются как есть.
- Instagram без картинки невозможен — такой пакет отклоняется. Instagram принимает только JPEG.
- Лимиты проверяются до любого запроса: X — 280 взвешенных символов (кириллица 1, эмодзи 2,
  ссылка 23) и не больше 1 кештега; Instagram — 2200 символов, 30 хештегов, 20 упоминаний;
  LinkedIn — 3000 символов после экранирования. Длинный текст **не обрезается**: пакет
  отклоняется с подсчётом, и не уходит ни в одну сеть.

### Публикация

```
python3 -m poster publish content/packages/2026-11-09-halving.json --profile kotleta --dry-run
python3 -m poster publish content/packages/2026-11-09-halving.json --profile kotleta
```

- `--dry-run` показывает для каждой сети точный текст, картинку, подсчёты и все запросы
  (секреты скрыты), ничего не отправляет и ничего не записывает.
- Профиль: `kotleta` (Facebook, Instagram, LinkedIn, X). Отдельные цели: `--targets fb:kotleta,x`;
  любая другая страница — `fb:ИМЯ`/`ig:ИМЯ`, если в `.env` есть её переменные (см. `KEYS.md`).
- Порядок: Facebook, Instagram, LinkedIn, X (платная сеть последней). Ошибка одной сети не
  останавливает остальные; в итоге по строке на сеть.
- Повторный запуск того же пакета пропускает уже опубликованное и повторяет упавшее. Если
  исход неизвестен (обрыв связи или ответ 5xx после отправки), сначала проверьте аккаунт, затем
  `--force-target ЦЕЛЬ`.
- Коды выхода: `0` — всё опубликовано; `1` — хотя бы одна сеть упала или исход неизвестен;
  `2` — ошибка в команде или пакете, ничего не отправлено.

### Остальные команды

- `python3 -m poster delete --target fb:kotleta --post-id ID` — удалить пост страницы
  Facebook, опубликованный этим постером (сначала пост читается тем же токеном, после удаления проверяется, что он исчез).
- `python3 -m poster records --last 20` — журнал публикаций (время, пакет, цель, id, ссылка).
- `python3 -m poster status` — расход X за месяц, срок токена LinkedIn, какие цели настроены.
- `python3 -m poster check-staging --page kotleta ФАЙЛ.jpg` — проверка пути картинки для
  Instagram (временное неопубликованное фото на странице, затем удаляется); ничего не публикует.

### Бюджет X

Каждый запрос к X заранее записывается в месячный журнал расходов по цене из настроек. Если
пост выведет месяц за `X_MONTHLY_CAP_USD` (5 $), он отклоняется до любого запроса к X —
спросите оператора. Пост с картинкой пока считается по 0,215 $, пока реальная цена не видна
в X Developer Console; после этого цены меняются в `.env`.

### Где лежит состояние

Журнал публикаций и расходов X — вне репозитория:
`~/.local/state/media-factory/poster/` (или `MF_STATE_DIR`, `--state-dir`). Права 700/600,
секретов там нет.

### Тесты

```
python3 -I -B -m unittest discover -s tests -t .
```
